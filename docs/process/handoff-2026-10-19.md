## Build and run
- Open `BranchiOS/YaYa.xcodeproj`, scheme **YaYa**. Don't use the BranchApp scheme: it builds a bare executable with no icon or launch screen.
- CLI: `cd BranchiOS && DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild -project YaYa.xcodeproj -scheme YaYa -destination 'id=<UDID>' -derivedDataPath build/DD-x build`
- The user's simulator is iPhone 17 `A161CDF2-3911-4AA8-BFA1-3689D6D85789`. Agents must never install to it or use `booted`. Use your own clone, by explicit UDID.
- There is no iPhone SE testing. Test on iPhone 17 and iPhone 17 Pro Max.
- Launch args are listed in `BranchApp/App.swift` and at the top of `CollaborationSessionView.init`. Always add `-noSplash` for screenshots.
- Berkeley Mono is not bundled, and the SF Mono fallback is accepted. Never re-add `UIAppFonts`, because it caused a blank screen.
